# Math 7 Reviewer

Reviewer for Grade 7 Mathematics: percentages, rational and irrational numbers, ordering rational numbers, number line, fractions, decimals, square and cube roots. Study notes, flashcards, match game, multiple choice, identification, problem solving and a mock exam. Every question has a clue.

This is a single self-contained `index.html` (styles and scripts inline). No offline cache.

Deployed to Vercel project `math7-reviewer` with Root Directory set to `math7-mathematics-q1`.
