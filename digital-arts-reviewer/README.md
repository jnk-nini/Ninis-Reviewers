# Digital Arts Reviewer

Reviewer for **Lesson 1: Digital Arts and Technology** and **Lesson 2: Reading Images, Symbolism, Meaning & Context, Visual Communication**.

Static site, no build step. Works offline through a service worker (`sw.js`). Starry Night theme (night and day).

- `notes.js`: lessons, topics, study notes (with ⭐ Must-know lists, memory tricks, exam traps) and the glossary/flashcard terms
- `bank.js`: 696 questions in the prof's formats: multiple choice, true or false, identification, fill in the blanks; every item has a clue and an explanation
- `app.js`: notes (lesson filter, expand all, essentials only, recall mode, brain dump, quick check), read-aloud (Web Speech API), drills, mock exam, flashcards with spaced repetition, progress
- `style.css`: styles
